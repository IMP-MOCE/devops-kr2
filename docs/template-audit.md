# Ревизия исходного шаблона

Исходный коммит: `3ee6c4bfda24df8cb4d61f8a27031813b3238338`. Ревизия выполнена без сборки дефектного образа.

| № | Файл, строка | Дефект | Последствие | Исправление |
|---|---|---|---|---|
| 1 | Dockerfile:1 | Плавающий тег python:latest | При следующей сборке может измениться версия Python и системных библиотек; результат не воспроизводится, скачивается другой базовый образ. | Использован уже загруженный python:3.12-slim. |
| 2 | Dockerfile:5–6 | COPY . . выполняется перед pip install | Изменение только app.py сбрасывает кэш установки всех зависимостей и замедляет повторную сборку. | Сначала COPY requirements.txt и pip install, затем COPY app.py. |
| 3 | Dockerfile, отсутствует USER | Приложение запускается от root | Уязвимость приложения позволяет выполнять действия с правами UID 0 внутри контейнера. | Создан системный пользователь app; задан USER app. |
| 4 | Dockerfile:9 | CMD в shell-форме | PID 1 становится оболочка; передача SIGTERM приложению может нарушиться, остановка задерживается до принудительного завершения. | CMD задан JSON-массивом, Gunicorn получает сигналы напрямую. |
| 5 | Dockerfile:9 | Gunicorn слушает 127.0.0.1 внутри контейнера | Трафик опубликованного порта поступает на сетевой интерфейс контейнера, а не на его loopback; запросы с сервера не доходят до приложения. | Приложение слушает 0.0.0.0:8002 внутри контейнера. |
| 6 | Dockerfile:8–9 | Порт 8000 вместо порта варианта 8002 | Публикация 8002:8002 не совпадает с портом процесса; соединение не устанавливается. EXPOSE сам по себе порт не публикует. | EXPOSE и bind приведены к 8002. |
| 7 | .env; отсутствует .gitignore | Файл .env с паролем отслеживается Git | Пароль шаблона доступен каждому читателю опубликованной истории; исключение файла только из следующих коммитов не устраняет утечку старого значения. | Удалён из индекса и рабочей копии, добавлено исключение; новый пароль создан только на VM. |
| 8 | Dockerfile:5; отсутствует .dockerignore | В контекст сборки попадают .env и .git | COPY . . переносит секрет и историю Git в слой образа; последующее удаление не стирает данные из старого слоя. | Добавлен .dockerignore; исходники копируются явно; .env.example содержит заглушки. |
